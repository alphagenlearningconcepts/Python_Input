The Text Trap!

input() turns ALL numbers into TEXT!

5 + 5 Result:
"5" + "5" = "55" ❌
✨ FIX: Wrap with int(input(...)) for REAL math!
📜

Golden Rules

✅ CORRECT
name = input("Name? ")

Variable box is on the LEFT of =

❌ WRONG
input("Name? ") = name

Never put input() on the left!

✅ CORRECT
age = int(input("Age? "))

Quote marks inside "" prompt!

❌ WRONG
age = input(Age?)

Missing quotation marks gives a syntax error!
